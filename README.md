# 🎓 SnapAttend – AI-Based Face & Voice Attendance System

 **Smart Attendance using Face Recognition + Voice Recognition**

SnapAttend is an AI-powered attendance system that automates classroom attendance using **facial recognition and voice biometrics**. It eliminates manual roll calls and provides a seamless experience for both teachers and students.

---

##  Overview
<img width="630" height="300" alt="snap-landing" src="https://github.com/user-attachments/assets/089396df-c227-47ac-b3bc-6bf1deea8365" />
<br>


Traditional attendance systems are time-consuming and prone to errors. SnapAttend solves this by leveraging **Computer Vision + Speech Processing** to automatically detect and mark attendance.

The system allows:
- Teachers to manage subjects and attendance effortlessly  
- Students to register using face & voice  
- Fully automated attendance from images or audio

## ✨ Features

###  Teacher Dashboard
- Subject creation & management  
- QR-based student enrollment  
- Automated attendance (image/audio)  
- Attendance logs & insights  

###  Student Dashboard
- Face login  
- Voice + face registration  
- Easy subject joining  
- Attendance tracking
